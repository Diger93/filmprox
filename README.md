# FilmPROx — канал обновлений

Здесь публикуются APK и update.json для автоматических обновлений FilmPROx.

- Манифест: https://github.com/Diger93/filmprox/releases/latest/download/update.json
- APK: https://github.com/Diger93/filmprox/releases/latest/download/filmprox.apk

latest/download/... всегда указывает на последний опубликованный релиз. Каждый релиз
содержит два ассета: ilmprox.apk и update.json. Приложение читает канал без токена.

Обновление установится только поверх сборки, подписанной тем же ключом. Скачивайте APK
только из официальных релизов этого репозитория.
